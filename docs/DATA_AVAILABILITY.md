# Data and artifact availability

The public release includes built-in fictional tasks and their deterministic
18/60-record JSONL export, source code, model metadata, offline regression tests,
and generic execution templates. These are sufficient to inspect the mechanism
and attempt a new controlled run in an authorized offline compute environment.

Historical raw benchmarks, original run ledgers, private source snapshots and
experimental evidence are kept separately. This release does not certify their
redistribution licenses or publish private prompts, logs, credentials or host
paths. Do not upload the private sibling directory or either recovery backup.

A new runtime invocation records its own source hashes and partition/model
digests. Historical reproduction additionally requires the exact archived data,
original source version, checkpoint and inference budget. A public release's
new path/entry-point hashes must not replace hashes inside old evidence.

Before sharing any measured evidence, independently review ownership, licensing,
privacy and consistency with the manuscript. Retain failures, incomplete cohorts
and adverse observations. Synthetic record accuracy is not attack success, and
passing the offline suite is not a new measured LLM result.
